# Proyecto-Videojuego
Mi videojuego se llama "The life"🤍/ El videojuego tratara acerca de la vida de un post-adolescente que debido a unos cuantos traumas que arrastra desde unos cuantos años le empezara a afectar significativamente a su vida, por lo que vivira algo que nunca a vivido
El genero del videojuego es narrativa y la plataforma de destino sera PC/Nintendo Switch/PS5
Su mecanica principal sera atravesar diferentes recuerdos del protagonista
El motor principal que utilizare es Unity
